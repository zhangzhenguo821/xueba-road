🔧 三步注入方案

Phase 1：知识骨架注入（CK12 → 芯片分类体系）
从好未来CK12知识图谱提取500+一级知识点，映射到现有297个芯片的category/subject字段。 补齐缺失的知识分类维度（如"运算能力""空间观念""数据分析"等课标维度）。
目标字段：chip.category, chip.subcategory, chip.knowledgePoint
Phase 2：例题注入（CMATH → 芯片解题步骤）
从CMATH提取G4-G6的300道开源数学应用题+步骤解析，按知识点匹配注入对应芯片的 chip.script（例题讲解）和模型的standardSolution.steps字段。
目标字段：chip.script, model.standardSolution.steps, model.variantTraining
Phase 3：知识图谱对接（CK12知识树 ↔ 学霸之路芯片树）
将CK12的500+知识点层级树与现有renderTree()渲染的知识树双向关联。 实现：点击芯片 → 加载CK12对应知识点的所有子知识点、前置知识点、变式题。
目标：芯片详情页新增"知识图谱视图"（前置/后继/关联知识点连线）

✅ 最终决策：先打穿 Phase 1 + Phase 2

  • 立即执行：CK12知识点 → 芯片分类体系映射（约500条知识点）
  • 立即执行：CMATH例题 → G4-6芯片解题步骤注入（约300道题）
  • 后续：Phase 3知识图谱可视化（需React Flow等交互组件）
  • 备选：cn-k12作为变式训练题库（需先筛选G4-6内容+确认商用合规）

⚠️ 注意：当前CK12和CMATH主要覆盖数学学科。语文和英语的开源内容极少， 需要从其他渠道（全国真题库、教材OCR、AI生成等）补充。
