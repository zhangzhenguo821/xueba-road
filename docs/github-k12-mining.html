🥈 Tier 2 — 条件可用 / 需额外处理

thl529/question-bank ⭐ 0 ⚠️ 仅供学习参考
小学1-6年级语数英选择题题库（JSON），约1,290道题。结构规范：题干+ABCD选项+答案+解析+知识点标签。按年级/学期/科目分36个JSON文件。附带抓取脚本可扩展。
📦 JSON (36个文件) 📝 1290道选择题 🛠 含抓取脚本 ⚠️ 无活跃维护
语文 数学 英语 可参考
Math23K (腾讯AI Lab) — 数据集 学术用途
腾讯AI Lab发布的23,164道中文小学数学应用题数据集。每道题含原始文本、分词文本、数学方程式、答案。主要用于NLP数学推理研究，已被近千篇论文引用。比 cmmath 更大更全。
📦 结构化文本 📝 23,164道题 🔬 学术级质量 🔗 base.ustc.edu.cn
数学 应用题 参考

功能全面的汉字工具JS库。支持拼音转换、笔画顺序、偏旁部首查询、成语接龙等20+功能。可用于语文芯片的"拆字学字""笔顺动画"等交互功能。

汉字笔画顺序动画和书写练习JavaScript库。支持简体/繁体，可嵌入网页展示正确笔顺。直接用于"生字书写"芯片的可视化教学。
语文 JS库 可视化

全国小初高大学PDF教材合集。目前仅有数学科目实际数据，其他学科标注了目录但数据未上传。PDF不可机读，需OCR处理。可作为教材权威参考，但不适合直接注入。

⚠️ 学科缺口：小学科学
目前未找到高质量的开源小学科学（教科版）题库/知识点项目。现有选项：
  • ChinaTextbookStudyFree 的 output/science/outlines/ 有AI生成的知识大纲和单元题（可用但需审核质量）
  • 商业数据集（2000万K12题库）覆盖科学科目，但不开源且收费
  • 建议：先用 ChinaTextbookStudyFree 的科学大纲建立芯片框架，后续再补充
