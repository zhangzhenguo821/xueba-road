# 🎓 学霸之路：四五六年级全科突破平台

> "不做复读机，做思维碎骨机。"

## 📋 这是什么？

这是给外包团队的**工业级产品原型交付包**。包含：

- **26个核心芯片** — 四五六年级语数外全国试卷高频失分卡点的完整解构数据
- **3个核心页面** — 痛点路由器（首页）、思维模型舱（核心学习页）、闭环诊断区（测试页）
- **7种Canvas交互引擎** — 数轴拖拽、跷跷板、胶卷周期、重叠面积、蝴蝶模型、动词爆炸、侦探连线
- **交付包导出系统** — JSON数据导出、纯文本导出、SOP模板、外包开工信

## 🌐 直接访问

打开 `index.html` 即可查看完整的可交互原型网站。


## 🔧 外包团队开发对接指南

### 数据对接
- `data.js` 中每条芯片包含5大核心字段：编码、痛点、诊断、芯片、真题
- 后端数据库表结构必须严格按照这5个字段设计
- 新增芯片只需在 `CHIPS` 数组中添加一条记录，前端自动渲染

### 视频对接
- 当前视频舱是占位符（黑框 + 播放按钮）
- 外包需替换为 HTML5 `<video>` 标签或嵌入腾讯云/阿里云视频链接
- 数据库需新增 `[视频URL]` 字段

### Canvas交互对接
- `canvas-interactive.js` 已实现7种交互模型的完整Canvas代码
- 外包可直接复用这些代码，或在此基础上开发更多模型
- 认知动作强熔断机制已内置：不完成交互 → 通关按钮锁死

### 闭环诊断对接
- AI纠偏面板已实现3种故障逻辑：信息提取/模型迁移/计算粗心
- 外包需接入真正的题目数据（从真题池随机抽取变型题）
- 通关硬指标：连续答对2道变型题 → 标记已通关

## 🚀 一键推送到 GitHub

```bash
# 1. 安装 gh CLI（如果没安装）
brew install gh

# 2. 登录 GitHub
gh auth login

# 3. 执行推送脚本
bash push-to-github.sh
```
